# ESG

ESG stands for environmental, social and governance: non-financial criteria some investors use to include or exclude companies. Providers of ESG data use different methods and can disagree about the same company.

In this app the ESG tag on a card ("screened", "not screened", "controversy") is demo data set by hand to show how an ESG filter behaves. It is not real ESG data and says nothing about the real company.
