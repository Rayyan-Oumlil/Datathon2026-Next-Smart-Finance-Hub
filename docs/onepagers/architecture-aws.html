Une application web Next.js et un service d'agent Python (Strands Agents), déployés dans us-east-1 par des scripts idempotents (infra/*.sh). Règle de conception centrale : le modèle ne calcule aucun chiffre — ses outils appellent l'API interne de l'application, et chaque appel au modèle se retrouve dans trois journaux recoupables.

Choix de conception

  • Chiffres par du code, mots par le modèle. Classement, pointage et rejeu sont des fonctions pures et testées, pilotées par rules/v1.json (versions affichées).
  • Toute action est proposée, jamais imposée. Aperçu avant / après sur la page, puis Enregistrer ou Annuler ; l'annulation est journalisée aussi.
  • Deux vérifications après le modèle. Chiffres sourcés et mots interdits dans le service d'agent, puis Guardrail Bedrock.
  • Journaux en ajout seul. Rien n'est modifié ni effacé ; une réinitialisation ouvre une nouvelle génération de session.

Composants et limites

  • Web : Next.js 15, React 19, TypeScript, français par défaut et anglais ; 1 666 tests.
  • Agent : Python, Strands Agents SDK, conteneur AgentCore ; 260 tests.
  • Données figées : instantané de 212 symboles (déc. 2020 à nov. 2026) versionné dans le dépôt, pour un rejeu reproductible.
  • Limites : base de connaissances Bedrock refusée par le compte (glossaire servi depuis le dépôt) ; une seule tâche Fargate ; cours canadiens différés.
  • Simulation seulement : aucune transaction réelle, aucun conseil en placement.
